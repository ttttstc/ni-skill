# excalidraw-aqua

The `excalidraw` view on a recreation of the inner/outer loop diagram in the README of Google adk-recipes'
Ambient Quality Agent (AQuA): https://github.com/google/adk-recipes/tree/main/core/python/ambient-quality-agent ,
shared on X by @Saboo_Shubham_: https://x.com/Saboo_Shubham_/status/2112428713979900248 .
The original is a landscape picture with the two loops side by side; for 4:5 and 3:4 it is turned 90° (inner loop on
top, deploy going down, the two dashed loop-backs on the sides). The motion and the handwritten notes are illustrative.
Keep the credit line when you publish.

    python3 examples/excalidraw-aqua/build_config.py
    python3 scripts/render.py --config examples/excalidraw-aqua/config-4x5.json --out aqua-4x5.mp4
