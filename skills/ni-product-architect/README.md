# ni-product-architect

面向产品、平台和云服务架构设计的基线生成 Skill。它从一个还不充分的产品或技术想法开始，通过概念对齐、批量访谈、现状分析、默认业界调研、架构决策、多视图设计和独立验收，生成可直接进入研发评审的 Markdown 产品架构基线。

## 适合的任务

- 新增一个云服务或平台能力；
- 对现有能力做较大增强；
- 兼容第三方协议、生态或产品能力；
- 需要把模糊需求收敛成研发可继续详细设计的顶层方案；
- 需要同时说明产品形态、L0/L1、主要接口、全局约束和验收标准。

## 不适合的任务

- 只需要快速比较两个架构方向；
- 直接写代码或详细接口定义；
- 设计数据库表、类、方法、线程池等内部实现；
- 默认对整个代码仓做逆向架构分析。

## 调用

Codex：

```text
$ni-product-architect 我需要为平台支持某项新能力，当前现状是……
```

Claude Code：

```text
/ni-product-architect 我需要为平台支持某项新能力，当前现状是……
```

用户只需要先给出目标和简短现状。Skill 会先完成核心概念对齐，再按阶段批量提出真正影响架构的 3–5 个问题；如有相关产品、架构、接口或设计文档，可直接一并提供。

## 默认工作方式

```text
概念对齐
→ 目标与范围访谈
→ 现状与差距
→ 多子代理公开调研
→ 关键架构决策
→ 产品形态与 L0/L1
→ 按需架构视图
→ 主要接口与全局约束
→ 测试与验收
→ 独立评审子代理
→ 修订至通过
→ 正式 Markdown
```

`ni-product-architect` 与 `think-like-architect` 相互独立，不调用也不依赖对方。前者面向正式产品架构基线交付；后者保持原有首层架构判断能力。
