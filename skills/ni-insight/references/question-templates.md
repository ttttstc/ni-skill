# 三个反直觉提问模板

> 本文是 ni-insight 第二轮「用户碰撞」的核心工具。这三个模板的作用，是把作者心里那个模糊的、说不清的直觉，逼成一句清晰的判断。

很多时候作者其实有想法，只是没成形。直接问「你想说什么」，得到的多半是话题不是观点。这三个模板换一种问法，从作者已经有的不满、吐槽、纠结里，把观点钩出来。

每个模板给：**完整话术 / 变体 / 追问技巧 / 怎么解读用户的回答**。

---

## 模板一：X 其实是坏的

**针对的角度类型**：反转型。

**完整话术**：

```
这个题材里，大家默认觉得「好」的那个东西是什么？

我们一起想想：那个被当成最佳实践、被当成理所当然的 X——
有没有哪种情况，X 其实是个坏东西？

不用是全盘否定，只要找到一个 X 反而帮倒忙的具体场景就行。
你自己有没有踩过这种坑——明明照着最佳实践做，结果反而更糟了？
```

**变体**：
- 偏经验的作者：「你按标准做法做，但心里隐隐觉得不对劲的那次，是什么场景？」
- 偏分析的作者：「X 这个最佳实践，它成立是有前提的。这个前提在什么时候不满足？」

**追问技巧**：
- 用户给了一个反例 → 追问「这种场景常见吗？还是很边缘？」。常见才有写的价值。
- 用户说「没有，X 就是好的」→ 换个问法：「那 X 被滥用、被用过头的时候呢？过量的 X 算不算坏？」

**怎么解读回答**：
- 用户能立刻举出一个具体踩坑场景 → 这就是反转型角度的种子，往下挖。
- 用户只能泛泛说「也有缺点」→ 还不够，缺点人人知道，反转要的是「在某条件下，缺点压倒优点」。继续追到具体条件。

## 模板二：Y 是症状不是问题

**针对的角度类型**：升维型。

**完整话术**：

```
这个题材里，大家都在抱怨的那个 Y 是什么？

我想问的是：Y 会不会其实不是问题本身，只是一个症状？
就像发烧不是病，是病的信号。

如果 Y 是症状，那真正的病在哪？大家忙着退烧，
有没有人去查过为什么会烧起来？
```

**变体**：
- 「大家都在修 Y，越修越累。会不会修错地方了——Y 只是某个更深的东西冒出来的泡？」
- 「如果把 Y 彻底解决了，你觉得问题就没了吗？还是过阵子换个形式又冒出来？」

**追问技巧**：
- 用户给了一个「更深的问题」→ 追问「这个更深的问题，是不是又是另一个东西的症状？」。升一层就够，别无限升，升到够不着地面就停。
- 用户绕回 Y 本身 → 引导：「我们换个方式问——什么样的环境 / 结构，会持续不断地生产出 Y？」

**怎么解读回答**：
- 用户指出了一个结构性原因（流程、激励、组织、约束）→ 升维型角度成立，这通常比就事论事的角度高级。
- 用户给的「更深问题」其实跟 Y 是一回事换了说法 → 没升上去，继续问。

## 模板三：Z 在某条件下负收益

**针对的角度类型**：时间型 / 反转型的精确版。

**完整话术**：

```
这个题材里，有没有一个被推崇的做法 Z——
那种「你就该这么做」的行业标准动作？

我想问：Z 在什么规模、什么阶段、什么条件下，其实是负收益的？
不是「不够好」，是「做了比不做还差」。

比如团队多大之前不该做、项目早到什么阶段做了纯属浪费、
什么前提不满足时 Z 就从资产变成负债。
```

**变体**：
- 偏工程的作者：「Z 这个做法，它的收益和成本各自怎么随规模变化？有没有一个交叉点，过了点之前做就是亏？」
- 偏判断的作者：「如果有人来问你该不该上 Z，你会先反问他什么？那个反问，就是 Z 的成立条件。」

**追问技巧**：
- 用户给了一个条件 → 追问「这个条件好判断吗？读者怎么知道自己在哪一边？」。能给出可操作的判断标准，角度才落地。
- 用户说「Z 总是好的」→ 试试极端：「团队只有一个人的时候也该做 Z 吗？项目活不过三个月也该做吗？」用极端逼出边界。

**怎么解读回答**：
- 用户给出了清晰的「条件 / 规模阈值」→ 这是含金量最高的角度，因为它直接能变成读者的决策工具。
- 用户给的条件很模糊（「看情况」「视团队而定」）→ 逼具体：「情况具体指什么？给我两个能区分的信号。」

## 三个模板之外：用户自己有角度怎么办

如果用户一上来就抛出了自己的判断，**不要走模板**，直接接住他的角度。但仍要带它过一遍验收：

- 这个角度在不在避雷区里（是不是其实大家都说过）？
- 挂得回素材吗（G1）？
- 撑得起 3 条支撑逻辑吗？
- 过得了朋友圈测试吗？

用户的角度优先，但「优先」不等于「免检」。如果用户的角度其实是主流观点换了个说法，要诚实告诉他，再用三个模板帮他往尖里磨。

## 碰撞的语气底线

全程用 G3 对话腔——你是在帮朋友想事情，不是在审稿。

- 不说「你的想法不够独特」，说「我觉得这个角度大家可能听过，我们要不要再往里挖一层」。
- 不说「请提供更具体的条件」，说「这个条件我有点抓不住，你给我举个例子？」。
- 可以表达自己的偏好（「这三个我偏 B」），但最终拍板的是用户。
- 用户磨了三轮还磨不出来，不硬撑——按 SKILL.md 的 G5 降级路径，诚实告诉他「我们今天没碰出来」，别凑一个假角度交差。
