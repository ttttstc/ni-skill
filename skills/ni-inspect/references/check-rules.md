# 预检规则与禁用词黑名单

> 本文是 ni-inspect 的检查依据。包含三组检查项的阈值、分级规则，以及**自带的禁用词黑名单副本**。

> **关于禁用词黑名单**：下方第 4 节的禁用词表**源自 ni-writer**（`ni-writer/SKILL.md` 禁区清单 + `references/ai_fingerprint_blacklist.md`），在此固化为独立副本。ni-inspect 不在运行时引用 ni-writer 的文件——基因一致，文件独立。ni-writer 的禁区清单若有更新，需手动同步此表。

---

## 1. 第一组：Metadata 检查

| 检查项 | 阈值 | 不达标级别 |
|--------|------|-----------|
| 标题长度 | 5-64 UTF-8 字节 | < 5 或 > 64 → WARNING |
| 摘要 digest | ≤ 120 UTF-8 字节 | > 120 → WARNING |
| 正文字数 | ≥ 200 字 | < 200 → BLOCKED |
| 图片数 | ≤ 10 张 | > 10 → WARNING |

字节按 UTF-8 算（一个汉字 3 字节）。

---

## 2. 第二组：内容质量检查

| 检查项 | 阈值 | 不达标级别 |
|--------|------|-----------|
| 禁用词命中 | = 0 | ≥ 1 → BLOCKED |
| 禁用标点命中 | = 0 | ≥ 1 → BLOCKED |
| 加粗密度 | 任一段加粗字数 ≤ 该段 15% | 超标 → WARNING |
| 标题 / 伪标题加粗 | 全部加粗 | 有遗漏 → WARNING |
| 金句 | ≥ 1 处可独立截图转发 | 0 处 → WARNING |

**加粗密度算法**：逐段统计，加粗字符数 / 该段总字符数。任一段 > 15% 即记 WARNING，报告里点出是哪一段。

**金句判定**：一句话抽出来单独读，仍构成一个有张力的判断 / 观点，就算金句。纯陈述、纯过渡句不算。

---

## 3. 第三组：结构检查

| 检查项 | 阈值 | 不达标级别 |
|--------|------|-----------|
| 模块总数 | ≤ 5 | > 5 → WARNING |
| verdict 数量 | = 1 | 0 个 → BLOCKED；> 1 → WARNING |
| callout 数量 | ≤ 3 | > 3 → WARNING |
| quote 数量 | ≤ 2 | > 2 → WARNING |
| steps 数量 | ≤ 1 | > 1 → WARNING |
| 模块注释语法 | 配对完整、语法合法 | 残缺 → WARNING |

模块通过 `<!-- :::xxx -->` 注释识别，规则与 ni-formatter 对齐。

---

## 4. 禁用词黑名单（自带副本，源自 ni-writer）

命中下列任意词 / 句式 = BLOCKED。

### 4.1 套话与学究腔（全禁）

首先、其次、最后、综上所述、值得注意的是、不难发现、让我们来看看、接下来让我们、本质上、归根结底、从根本上、不言而喻、毋庸置疑、不可否认、说白了、意味着什么、换句话说

### 4.2 AI 高频词（禁用或严格降频）

赋能、生态、范式、维度、抓手、闭环、链路、纵深、底座、底层逻辑、心智、复盘、对齐、拉通、颗粒度、护城河、范式转移、增长飞轮

### 4.3 意义膨胀句（全禁）

标志着……的重要时刻、见证了……的演进、折射出更宏大的……、为……奠定了基础、开启了……的新纪元

### 4.4 促销腔（全禁）

蓬勃发展、欣欣向荣、熠熠生辉、底蕴深厚、座落于、位于风景秀丽的、享誉海内外、备受瞩目

### 4.5 结构性套话（全禁）

「让我们来看看」「在当今……的时代」「随着……的发展」；连续 bullet 超过 3 个。

### 4.6 表演性废话（全禁）

「我本来没打算认真看」「说实话我一开始没当回事」「本来不打算写这个」「坦白说我是被逼的」；以及替读者说话的「你可能觉得」「我知道你在想什么」「你一定会说」。

### 4.7 空泛工具名（全禁）

「AI 工具」「某个模型」「相关技术」「某 AI」——必须换成具体名称（Claude Code / Codex / Gemini / Kubernetes / Argo CD / Istio 等）。

---

## 5. 禁用标点（全禁）

命中 = BLOCKED。

| 禁用 | 说明 | 应替换为 |
|------|------|---------|
| 冒号 `:` `：` | 中英文冒号 | 逗号 |
| 破折号 `——` | | 逗号或句号 |
| 双引号 `"" ""` | | 「」或不加引号 |
| 颜文字 | 各类 emoticon | 删除 |
| 多问号 `？？` | | 单问号 |
| 叠句号 `。。` | | 规范省略号 `……` |

注：代码块、行内代码内的标点不计入（那是代码，不是正文）。模块注释 `<!-- :::xxx -->` 内的标点也不计入。

---

## 6. 分级总表

| 级别 | 触发项 | readiness 影响 |
|------|--------|---------------|
| **BLOCKED** | 禁用词命中、禁用标点命中、verdict 缺失、正文 < 200 字 | → blocked，必须回 ni-writer 修 |
| **WARNING** | 加粗密度超标、digest 超长、标题/伪标题加粗缺失、金句缺失、模块超限、标题长度异常、图片超 10 | → degraded（无 BLOCKED 时），可知情跳过 |
| **INFO** | 模块数偏多但未超限、句长单调、其他不影响发布的观察 | 不影响 readiness |

`readiness` 最终取值：
- 有 BLOCKED → `blocked`
- 无 BLOCKED 有 WARNING → `degraded`
- 全清爽 → `ready`

---

## 7. 检查的边界

ni-inspect 只体检、只定位、只建议，**不改文章**。修改是 ni-writer 的活。报告里的修复建议要具体到「把这句的『赋能』换成『让……能做到』」这种程度，但执行交还给作者或 ni-writer。
