# ni-poster

`ni-poster` 是唯一公开的海报 skill，内部包含四种风格。它会先确定风格，再生成图片；如果用户没有说清楚，skill 会通过简短访谈引导选择，不会静默套用默认风格。

## 最快用法

已知道风格时，直接使用短参数：

```text
/ni-poster s 把这句话做成极简纸刊：夏天结束得很轻
/ni-poster g 保留这张照片，做成撕纸插画融合海报
/ni-poster d 用这张照片做场景提炼，最终不保留照片
/ni-poster a 保留原照片，在下方生成干净抽象面板
```

不知道选哪种时，直接描述主题：

```text
用 ni-poster 做一张关于雨天的海报
```

skill 会先询问照片是否保留，以及想要哪种画面关系，确认风格后再生成。

## 四种风格

| 参数 | 风格 | 最直白的特点 |
| --- | --- | --- |
| `s` | Standard | 极简纸刊，大留白、小主体、旧纸扫描质感 |
| `g` | Gathered Scenes | 保留照片，照片与撕纸插画融合 |
| `d` | Scene Distillation | 不保留照片，只提炼成独立抽象插画 |
| `a` | Photo Abstract Editorial | 保留原片，下方接干净象牙色抽象面板 |

### 一眼区分照片风格

- 照片与撕纸插画融合：`g`
- 原照片加下方抽象面板：`a`
- 最终不出现照片：`d`
- 没有特定照片处理、想做极简纸刊：`s`

## 未指定风格时如何访谈

如果有照片，skill 会先确认原照片是否需要出现在成品中：

- 不保留照片：选择 `d`。
- 保留照片：继续确认是“撕纸插画融合”还是“原片 + 抽象面板”，分别选择 `g` 或 `a`。

如果没有照片，skill 会确认用户想要：

- 极简大留白纸刊：选择 `s`。
- 从主题或文本提炼成独立抽象插画：选择 `d`。

每次只追问一个未确定维度。风格未确定前不生成图片。

访谈只负责选择风格，不会修改、混合或削弱任何子风格的原有能力；确认后按对应规则原样执行。

## 直接判型用语

这些直白表达可以跳过访谈：

| 用户表达 | 路由 |
| --- | --- |
| `极简纸刊`、`大留白小主体` | `s` |
| `撕纸边`、`照片与插画融合`、`拾景纸刊` | `g` |
| `不保留照片`、`场景提炼`、`照片只作参考`、`单色块模式` | `d` |
| `照片＋抽象面板`、`原片下方接抽象面板`、`照片抽象编辑` | `a` |

`照片`、`保留照片`、`抽象`、`纸感`、`ZINE`、`杂志风` 等泛词不能单独确定风格，skill 会继续追问。

## 照片要求

- `g` 和 `a` 必须有参考照片；缺少照片时会要求上传并等待。
- `d` 可以使用照片，也可以使用明确的主题或文本作为语义来源。
- `s` 不要求照片。

## 路由优先级

1. 显式短参数：`s`、`g`、`d`、`a`。
2. 显式风格名。
3. 能唯一确定画面关系的直白描述。
4. 信息不足时进行访谈，直到风格确认。

完整别名仍可使用：`standard`、`gathered`、`distillation`、`photo-abstract-editorial`。推荐日常使用短参数。
