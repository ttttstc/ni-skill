# 底图与材质规范

## 从形体出发

以画面形体、姿态和大曲面承担视觉重心。主题只需要足够辨认，不为了说明概念塞入屏幕、标签、箭头和碎道具。人物、机器人、器物、群像都可以使用这套材质，不强制古希腊人物。

- 默认暖灰平墙与象牙白浅浮雕，柔和低反差静态光照。
- 人物完整入画；无用户要求时留约 5%–8% 外边距，检查手、脚、翅膀与尾部。
- 衣服只保留少数宽衣褶；机器人用流畅外壳与可辨认关节，减少碎拼缝和玩具感。
- 皮肤、头发、羽毛以大面为主；五官、指关节、曲面转折仍须存在。
- 不加颗粒、脏污、深刀刻、密集皱纹、强环境阴影或烘焙金属高光。
- 横幅、竖幅、方图按构图选择；展示 `height:auto` 或一致 `aspect-ratio`，不得用 `object-fit:cover` 裁主体。

“减少碎细节”和“保留有效法线细节”同时成立：底图避免杂乱装饰，法线仍需描述眼睑、鼻梁、指节、衣褶圆边与曲面微起伏。不能把人物做成光滑塑料块。

## 四份配准资产

| 文件 | 含义 | 硬约束 |
|---|---|---|
| base | 静态白石底图 | 保留已认可内容、构图及原始字节 |
| normal | RGB 表面方向数据 | 与底图同尺寸同构图；没有材质色、白高光或投影 |
| mask | 灰度前景覆盖 | 黑色背景、白色主体；空隙为黑，边缘向内羽化 |
| clip | 白 RGB + alpha 覆盖 | alpha 等于 mask；用于最终背景隔离 |

法线以 RGB 解码为 `2 * RGB / 255 - 1`，再归一化。默认参考中红色随向右朝向增加，绿色随向上朝向增加，蓝色为正向 Z；像素坐标 y 向下不等于表面坐标 y 向下。不要凭 OpenGL/DirectX 名称直接翻绿通道，在同一 renderer 中用左右光源验证凸凹与朝向。

平面法线近似 `(128,128,255)`。生成图可能含边缘光晕、透明度或尺寸偏差，先检查再整理。脚本只在 mask 为零的位置归平法线；不会修复前景错误曲面。

法线重采样须解码为向量、线性重采样、重新归一化后编码，禁止把它当照片调色、锐化或大范围模糊。宽高比例一致也不代表配准一致；检查眼鼻、手指和器物边缘的实际位置。改变姿态、头部或衣褶需要新法线。

## 遮罩容易失败的位置

拱门、双腿、翅膀、手臂间和器物之间的空气应为零；月牙、细流、指尖、机械鸟脚等细实体应保留。全局填洞和形态学闭运算会把空气填成金属片，只能在已确认属于实体的局部修补。

遮罩误把墙面投影算进主体时，反光会污染背景。遮罩漏掉实体时，图像会出现白石缺块。先叠加 mask 看轮廓，再用全幅金属渲染检查；只看灰度图不足以发现所有错误。

最后合成顺序：原 WebGL 输出 → `destination-in` 乘 clip → `destination-over` 填固定墙色 → 恢复 `source-over`。每帧执行。不能用整个画布的 CSS 混合模式代替前景隔离。

## 沿用的效果参数

| 参数 | 当前模板值 | 用途 |
|---|---|---|
| metallic | 0.85 | 银灰金属混合 |
| ambientLight | 0.06 | 金属暗部 |
| lightIntensity | 0.4 | 游标光照 |
| specular | 1.1 | 高光强度 |
| cursorAmbient | 0.19 | 游标附近环境亮度 |
| introDuration | 4.7 秒 | 云纹理入场 |
| smudgeShrinkSpeed | 0.58 | 擦痕侵蚀 |
| smudgeBrushSize | 0.20 | 认可双人样片默认；按目标场景覆盖 |

原站组件默认笔刷为 0.24；实际实例出现 0.20、0.24、0.15。固定左中右光源属于诊断模式，绑定全白揭示纹理，保持 `revealEnabled:1`；设为 0 会同时关闭原 shader 的游标光照。正式互动恢复双缓冲擦拭纹理和游标跟随。

复制原 renderer 时保留纹理线性色彩空间、采样方式、UV 方向和双缓冲流程。正常法线不能按颜色贴图套用 sRGB 变换。更换引擎时需重新校准，不把参数数字一致当成视觉一致。
