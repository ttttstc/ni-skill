# 金属浅浮雕

用清楚的形体承载光影。默认交付底图、法线、遮罩和本地可运行的互动 HTML；用户只要静态图时，按静态模式停止。

## 先确定交付

读取用户图片、页面或主题，先明确主体、数量与朝向、构图比例、保持项、参考风格、输出目录，以及以下模式。信息已够就执行，只追问会改变结果的缺口。

- **完整流程**：白石底图 → 配套法线 → 精确遮罩 → 银灰金属互动样片 → 验收与打包。
- **静态浮雕**：只交付白石浅浮雕底图和实际提示词，不生成法线、不接动效。
- **静态金属图**：优先从已验收的配套材质与 shader 截取固定光源渲染；用户明确要直接生图时可以生成，并注明它是光照烘焙的静态作品。

新风格或没有认可样片的批量任务，先做一张包含代表性细节的校准样片。若用户已指定认可样片并授权整套适配，直接沿用，无须重复确认。尚未授权扩展时，先交付样片让用户审视。

## 视觉标准

生成前读取 [references/visual-and-material.md](visual-and-material.md)，写提示词时读取 [references/prompts.md](prompts.md)。

1. 白石或象牙白浅浮雕，平滑大面、宽而少的衣褶、完整轮廓。柔光不等于失去五官、手指和关节。
2. 金属态呈银灰，亮部沿曲面移动。眼鼻、手部、衣褶边缘在高光和暗部仍可辨认，不形成吞掉结构的大块软亮斑。
3. 法线与底图同构图、同尺寸、同 UV；保留内部曲面。不能把亮度图染成紫色，也不能以强模糊的明暗梯度和外轮廓距离场充当合格法线。
4. 遮罩只覆盖浮雕实体。手臂间、拱门内、双腿间等空气保持背景；不把投影和外发光算入主体。
5. 背景采用固定纯色，默认 `#DDDCD7`。反光、擦拭、入场与消退均不能改变遮罩外的背景像素。

## 制作

### 1. 底图

用户提供已认可底图时直接复用，记录哈希。需要新图或图像编辑时，优先使用当前原生 imagegen 能力；本地参考图先实际查看，并标明“编辑目标”与“风格参考”。参考角色不自动成为新画面的角色。

内置工具不可用时说明缺口。不要为了本流程自动改用付费 API、配置密钥或下载法线模型。用户已指定生成器时遵守其选择。每张图保存实际提示词、工具返回的源文件和选用版本。

先看数量、肢体、朝向、轮廓、衣褶和机械结构；局部失败只修对应部分。没有要求时不加文字、品牌、额外角色或技术道具。展示原比例静态图；用户要求先审底图时在这里停止。

### 2. 配套法线与遮罩

法线生成以当前底图为精确编辑目标，使用用户参考法线或随技能附带的 `assets/reference/normal.png` 作为编码和细节参考，禁止借用参考图的构图。

使用 RGB 表面方向数据：平面及背景为 `(128,128,255)`，左右变化对应红通道，上下变化对应绿通道，正向 Z 对应蓝通道。方向约定必须与 renderer 实际核对。生成的是数据贴图，最终页面显示白石和银灰金属，不显示紫色法线。

法线输出为不透明 RGB 平面，调用生图工具时明确要求这一背景；透明主体提取另用透明背景，不混用两种输出。

按轮廓生成或提取遮罩。透明源图优先使用真实 alpha；不透明图片可用分割工具辅助，但须检查细手指、细流、月牙与所有内部空隙。边缘只向内羽化，外部为严格零覆盖。

普通代码只用于数据整理、向量重采样和遮罩合成，不替代 imagegen 的视觉编辑。换底图后，旧法线和遮罩须重新配准；不同素材不能只按宽高拉伸拼接。

### 3. 互动样片

随技能提供 `assets/runtime/` 中的 Athens 浮雕 renderer、Three.js 与云纹理，`assets/template/` 为独立审图页。它们没有原项目绝对路径或 CDN 依赖。模板复用原 shader、双缓冲擦拭与消退参数；背景隔离只处理最终 2D 合成，不修改 shader。

运行技能内脚本（将路径换成当前技能目录与真实输入）：

```text
python <skill-dir>/scripts/build_preview.py --base base.png --normal normal.png --mask mask.png --output picarts/<slug>/v001
python -m http.server 4187 --bind 127.0.0.1 --directory picarts/<slug>/v001
```

依赖：Python、Pillow、NumPy；先检查现有或宿主提供的运行时。脚本生成 `mask.png`、`clip.png` 和背景归平后的法线，并保留底图原始字节。输入尺寸不匹配默认拒绝；仅分辨率变化且构图已核对一致时，显式加 `--resize-normal`，执行向量重采样再归一化。RGBA 遮罩用 `--mask-channel alpha`。

默认笔刷 `0.20` 沿用认可样片；原站实例另有 `0.24` 和 `0.15`。严格复刻指定场景时读取该场景参数，使用 `--brush` 对齐，不能声称统一值匹配所有场景。模板可切换白石、互动、固定左/中/右光源金属态。

首屏 Rive 倒水是独立能力，本模板不含倒水动画。只有用户明确要求这一入口时，另查对应 Rive 文件、状态机和文案，不能用正文 shader 冒充 Rive。

## 验收与交付

完整读取 [references/acceptance.md](acceptance.md)。先检查真实渲染细节，再检查运行行为；自动检查不能替代视觉审视。

桌面鼠标及触控模拟检查可使用现有浏览器工具，或运行：

```text
node <skill-dir>/scripts/verify_preview.mjs --url http://127.0.0.1:4187 --output picarts/<slug>/qa --module <existing-playwright-module> --browser <browser-executable>
```

`--module` 和 `--browser` 可省略以使用现有 Playwright 默认安装。不要为验收假设某台机器的浏览器路径。检查输出包括前景变化、鼠标按住、离开/触控结束后消退、遮罩外背景差值、比例与资源错误；触控模拟要如实注明。

交付底图、法线、灰度遮罩、RGBA clip、HTML 与运行依赖、提示词、参数与文件哈希、QA 截图和结论。正式输出使用版本目录，不覆盖认可素材。仅静态模式交付对应图片和提示词即可。

展示可打开的预览与图片绝对路径。区分底图完成、材质配准、运行通过、视觉通过及用户认可；新作品由二维图生成法线时，不声称复原了原三维几何或反光逐像素相同。质感未达标时保留失败图，回到法线或底图；不要扩到整套，也不要靠提高 specular 掩盖问题。

`assets/reference/` 提供配套底图、法线、遮罩和金属渲染图，作为形体与反光细节的校准锚点。`assets/runtime-lock.json` 锁定运行文件哈希；更换运行文件后必须重新校准与验收。
