# CI prompt 的离线执行记录

[任务.md](./任务.md) 是从白鹭答复代码块中直接提取的提示词；执行者只收到它、[材料](./材料/资料说明.md) 和本目录产物写入权限，没有收到 Skill 或评分判据。

[答复.md](./答复.md) 保留完整执行结果，包括严格留出条件未通过、目标可行性尚未证实的结论。[审计.json](./审计.json) 与[复核结果.json](./复核结果.json) 记录程序检查及执行者自己的文字修正；这些字段不是独立业务真值。

## 复现

新建一个空目录，仅复制 `离线分析.py`、`复核.py`、`任务.md` 和整个 `材料/`。在该目录依次执行：

```console
python 离线分析.py freeze
python 离线分析.py replay
python 复核.py
```

Python 标准库足够。JSON 使用新建模式写入，不要把归档 JSON 复制到复跑目录；不要在当前记录目录原地重跑。脚本是这一批构造材料的分析快照，包含固定规则和案例文字，不能作为通用 CI 分析器。

归档文本统一为 UTF-8/LF，答复中的本地绝对路径改为相对路径；文字内容没有重写。JSON 内的哈希保留原 Windows 运行记录，可能与规范化后的归档字节不同。原始与发布字节哈希分别见[上层结果记录](../results.json)。新目录复跑会生成与该次运行一致的新哈希；时间戳和派生哈希不要求逐字一致。

维护者独立复跑的结果见[复跑核对](../复跑核对.json)，重新解析原始 CSV 的统计与显式链见[客观核对](../客观核对.json)。这些只检验可复现性与可追溯性，不证明留出盲化、处置合理性或生产收益。
