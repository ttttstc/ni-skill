2026-10-20 至 21。首轮对同一开放 CI 任务运行修改前后的 Skill，新版另运行培训任务及两个边界场景；再把新版 CI prompt 交给新的执行者，完成一次离线验证。最后由未参与生成的独立子 Agent 统一评分，维护者完整复核并复跑脚本。

两份 CI 都把“日报加关键词重试”改成失败时的下一步判断与同一事件的接续。改进稿更明确要求主要对照、事件与决策时点两种分母、主动尝试推翻假设，并减少说明与 prompt 重复。对照稿则明确提醒已读完整材料不算独立盲测；改进稿没有把这一点交代清楚，反馈扣 1 分。答复字符数由 3188 降到 2727，代码块内 prompt 由 2354 变为 2377；改善主要在减少重复说明，不能声称 prompt 本身更短。

培训 prompt 从“多一个答案入口”改成“让新人选择下一步、守住承诺边界、知道何时升级”，用首轮未揭答案的练习收集真实作答与犹豫，按反馈修订演练或手册。它同时保留规则不清、权限不足和合理审批等解释。这个场景只检验 prompt，没有真实新人作答或迁移测试，也没有对应的旧版运行，不能据此证明培训效果或版本优势。

私人随笔保留三条已知细节和私人表达目的，没有编造经历、套增长指标或写正文。材料不足场景没有猜内部规则，将第一步限定为还原一例疑似误判所需的证据。简单场景通过不代表开放任务的目标想象能力已被证明。

## 实际执行与维护者复核

[执行 prompt](./execution/任务.md) 直接取自白鹭答复中的代码块，执行者只得到它、相同离线材料和新产物写入权限，没有得到 Skill 或评分判据。完整结果见[执行答复](./execution/答复.md)，脚本与复现步骤见[执行目录说明](./execution/README.md)。

维护者在新目录依次运行 `离线分析.py freeze`、`离线分析.py replay`、`复核.py`。七份 JSON 去除运行时间与派生哈希后语义一致，报告只去除路径差异后相同；详见[复跑核对](./复跑核对.json)。重新解析原始 CSV 的[客观核对](./客观核对.json) 与事件关联相符：24 次运行、14 次失败、9 条显式失败链；8 次 retry 记录中 3 次记为恢复、5 次未恢复。34 分钟只是后五次已记录的人工活动，不能解释成可实现的节省。

能够核对的行为包括：两轮 HTTP 403 保留独立事件；同链重复失败更新建议；相同超时词在 verify 与 fetch 对应不同核查方向；无显式关联的跨提交成功不直接关闭失败链。程序为 14 个决策点传入历史前缀，处理表在建议生成后才读。

**严格留出未通过。** 执行者在冻结前已经读过后段记录，规则中还手写了后段出现的 fetch 超时组合。前缀输入隔离不能消除设计者已见答案的影响。执行者主动披露失败，复核脚本修正报告表述；这提高了结论的可信度，不能使被污染的试验恢复有效。

还有三项限制：

- 脚本的规则、部分案例与报告文字是针对这批材料手写的。当前事实能与原表核对，不代表通用分析器或对另一批材料的自动验证能力。
- 处置记录没有动作时间、根因真值和替代动作结果。后段只有 3 个失败事件、4 个决策时点；没有证据判断建议优于原做法，更不能证明故障、通知或人工时间减少。
- 决策时间采用 `started_at` 作标签，未独立记录日志和失败状态的实际可见时间。程序前缀检查不能升级为真实在线时序证明。

只有新版 prompt 做了实际执行，对照稿没有对应执行；不能从这种不对称推断版本效果。文字自述和审计 JSON 的声明不替代完整工具轨迹；本轮实际文件证据限于保留产物、静态代码核对及维护者复跑。

## 最终源码的定向复核

首轮失败后只修正已见材料与独立验证的关系，不改场景、判据或首轮答复。最终稿的 CI prompt 与独立复核记录单列；这次只检查提示词，没有再运行业务验证，也不把首轮执行算成最终源码的执行结果。

[最终完整 prompt / 海棠](./responses/ci-final.md) 保留“同一事件持续判断下一步，并找出值得消除的复发问题”的目标，同时明确：

> 当前所有材料都已用于选题和设计这个任务，不能再把其中某几天称作独立留出集。

新的独立评分者只收到这一份请求、答复、材料与原判据，不知道版本或修正内容。五项各 4 分，总分 20/20；四项预期通过、四项关键失败均未命中。[完整定向评分](./targeted-scoring.json) 保留理由、39 条精确引文及证据边界，维护者逐条核对。首轮另有 137 条引文也已核对。

这支持最终 prompt 正确区分已见材料与独立验证，没有证明它在新样本上有效。独立评分者不同、每份答复只运行一次，不能用 19 到 20 的变化推断稳定提升；也没有新增生产验证或 Claude Code／OpenCode 实际加载验证。
