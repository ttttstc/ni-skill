# be-ambitious 行为验证

这组构造的自然请求检查目标想象、专业证据和任务边界，不使用真实客户资料。

请求、预期和关键失败条件见 [cases.json](./cases.json)。实际运行的请求、Skill 快照哈希、完整答复和独立审阅见 [results.json](./results.json)。未运行的案例不计为通过。

## 怎样复核

1. 运行前固定请求、判据、Skill 快照和停止条件。本轮只运行两个相关请求，各一次，不反复调参。
2. 每份答复使用新的独立上下文，只提供自然请求、一份 Skill 及同目录说明。目录使用中性标签，说明中去掉验证入口；执行者不接收判据或其他答复。
3. 使用宿主默认启动规格，不指定模型或推理覆盖。仅允许写各自的答复文件，不执行业务方案。
4. 答复完成后，由独立上下文阅读完整输出和预定判据，检查关键失败；维护者再完整复核。

SHA-256 按 UTF-8、LF 换行、无 BOM 计算。修改 Skill 后重新核对快照，不能沿用旧版本证据。公开答复仅将本机绝对工作目录替换为占位符。

## 本轮范围

2026-10-20 移除跨领域迁移要求后，重新检查两个场景：投诉日报需求能否展开到更高层目标，精确的 CSV 列名修改能否保持简短且不扩大范围。这是当前版本的定向检查，不作版本优劣比较。

独立审阅与维护者复核均未发现这两份输出触发预定关键失败。其余三个案例本轮未运行。

旧版的五组对比记录对应已被修改的 Skill，不再作为当前版本证据；历史内容可从 Git 提交 `132b3723bcf8b0e11b3bed4e21dcab6d6f635772` 查看。

## 证据边界

这里只判断显式提供 Skill 后的可观察输出。宿主未向主助手提供子 Agent 的完整工具访问轨迹，实际读取、检索和其他工具动作不可独立判定，不以自报替代。

结果只覆盖 Codex 原生独立上下文的两个单轮样本，不证明跨模型稳定性、生产效果或 Claude Code／OpenCode 的真实加载行为。底层模型版本未独立核实。

GitHub CI 运行仓库已有的离线契约与 README 审计；模型行为验证不在 CI 自动执行。
