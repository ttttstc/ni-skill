# 热点判断与调研方法

> 本文是 ni-research 的方法参考：怎么判断热度、怎么决定写作时机、怎么给素材分级、怎么扫竞品。

---

## 1. 热度趋势判断

把选题的热度归到三档：

| 档 | 信号 | 含义 |
|----|------|------|
| 上升 | 近期讨论量明显增加、新发布 / 新事件带动、搜索量走高 | 趋势在你这边 |
| 平稳 | 长期被讨论但没有新触发点、讨论量稳定 | 常青话题，靠角度取胜 |
| 下降 | 讨论量回落、热点已过、新话题盖过 | 趋势在你对面 |

判断时挂具名来源——「我看了 X 平台近一个月的讨论」「Y 的发布说明里提到」。不要凭感觉写「很热」。

---

## 2. 写作时机决策树

热度判断完，决定现在发还是等。

```
选题热度在上升？
├─ 是 → 你有独特角度吗？
│       ├─ 有 → 现在发。趋势 + 角度，最佳窗口
│       └─ 没有 → 等等看。先去 ni-insight 挖角度，别裸追热点
│
├─ 平稳 → 常青话题，时机不是关键，角度才是
│         → 现在发，但 ni-insight 那关必须够尖
│
└─ 下降 → 热点已过，追是追不上了
          ├─ 你有「事后复盘 / 反共识」角度 → 可以发，但要换姿势
          │   （不再是「这是什么」，而是「当时大家都看错了什么」）
          └─ 没有 → 劝退选题，或归档等下一个触发点
```

核心原则：**ni-skill 套件不靠裸追热点取胜，靠角度取胜。** 热度只决定窗口大小，角度决定值不值得写。时机的结论写进 research.md，但最终是否动笔由 ni-insight 的角度门槛把关。

## 3. 素材质量分级

每条素材按可核实程度分三级：

| 标记 | 含义 | 处理 |
|------|------|------|
| ✅ | 有具名来源、有链接、可追溯 | 正常使用 |
| ⚠️ 待核实 | 记得有这回事，但找不到确切出处 | 保留，但标清楚，提醒用户发稿前自查 |
| `[降级采集]` | WebSearch 不可用，来自 LLM 训练数据 | 保留，显式标注，整批提示未联网核实 |

具名率 = ✅ 条数 / 总条数，要求 ≥ 60%。

**好素材的样子**：具体到一个工具名、一个数字、一句可引述的话、一个能复述的案例。
**坏素材的样子**：「业界普遍认为」「相关研究表明」「越来越多的人」——这种是常识复述，不算素材。

---

## 4. 竞品扫描策略

目标是摸清「这个选题别人都怎么写的」，产出二分清单。

**检索方向**：
- 同领域头部公众号 / 博客的相关文章
- 技术社区（讨论帖、问答）里的主流说法
- 官方文档 / 发布说明里的「标准叙述」

**二分归类**：
- 一个观点如果你在 2 个以上来源都见到 → 归「已被说过」，它是避雷区。
- 一个角度你扫了一圈没人正经讲过 → 归「尚未被覆盖」，它是 ni-insight 的富矿。

**每条「已被说过」必须带出处**，否则 ni-insight 没法判断这个避雷区是否真实存在。

竞品主流观点至少 3 条。扫不到 3 条有两种可能：选题太冷门（可能是机会，也可能是没人关心），或检索不够——先扩大检索，仍不足才标「竞品分析不足」。

---

## 5. 调研的边界

ni-research 只备原料，不挖角度。

- ✅ 该做：摸热度、扒竞品、采素材、粗列方向。
- ❌ 不该做：深挖反直觉判断、锁定核心论点、做用户碰撞——这些是 ni-insight 的活。

「潜在角度」一栏只写方向（「可以从成本角度切」「可以从时间变化切」），不写成型的论点。越界了反而会框死 ni-insight 的发挥。
