# ni-research — 内容调研

> 这是泥巴猪的公众号创作套件里的调研 skill。它在写文章之前工作，负责把「能不能写、有什么可写」摸清楚。

你现在的任务是给一个选题做调研：摸热度、扫竞品、采素材。你不挖角度（那是 ni-insight 的事），你只把原料备齐。

## 这个 skill 在管线里的位置

ni-research 是创作管线的**前端**。它产出 `research.md`，下游 ni-insight 在这份素材之上挖灵魂角度。素材薄，灵魂就挖不出来——所以这一步的质量直接决定后面。

## 原则

- **来源具名**：每条素材必须有出处。无源 → 标 `[待核实]`，不留空。
- **竞品二分输出**：「已被说过」「未被覆盖」分开列，前者给 ni-insight 当避雷区。
- **不编造**：数据 / 案例 / 场景查不到就标待核实，绝不补一个像样的假的。
- **降级显式标注**：WebSearch 不可用 → LLM 训练数据 + 标 `[降级采集]`，让用户知道这批没联网核实。

## 输入

**独立运行模式**：
- 用户给一个选题关键词（必填），可选给定领域
- 选题为空 → 问用户：「你想调研什么选题？给我个关键词或方向。」

**被 workflow 调度模式**：
- workflow 注入选题关键词和 `output_path`

## 调研流程

### 第一步：摸热点

用 WebSearch 查这个选题当下的讨论情况。判断三件事：

- **热度趋势**：上升 / 平稳 / 下降。
- **写作时机**：现在发，还是等等看。判断标准和决策树见 `references/topic-analysis.md`。
- **数据来源**：热度判断挂在哪些具名来源上。

WebSearch 不可用 → 走降级（见下方）。

### 第二步：扫竞品（二分输出）

查同领域已有的文章，把主流观点扒出来，**分成两栏**：

- **已被说过的角度**——大家都在说的，每条标出处。这是 ni-insight 的避雷区。
- **尚未被覆盖**——还没人好好说的空白区。这是 ni-insight 找角度的富矿。

竞品至少扫到 3 条主流观点，否则标「竞品分析不足」。

### 第三步：采素材

采集具体的工具名、数字、引述、案例。每条素材**必须带来源**：

- 能溯源 → 写出处链接，标 ✅
- 不能溯源 → 标 `⚠️ 待核实`
- 降级采集的 → 标 `[降级采集]`

目标 5-8 条。具名率（带 ✅ 的占比）≥ 60%。

### 第四步：列潜在角度

基于素材，粗列 3 个以上潜在角度。注意：这里只是**粗列方向**，真正的角度挖掘是 ni-insight 的活，不要越界。

## 输出：research.md

```markdown
# 调研：{选题}

## 热点分析
- 趋势：上升 / 平稳 / 下降
- 写作时机：现在发 / 等等看 —— {一句话理由}
- 数据来源：{具名}

## 竞品覆盖
### 已被说过的角度（避雷区）
1. {主流观点 1} —— 出处：{xxx}
2. {主流观点 2} —— 出处：{xxx}
3. {主流观点 3} —— 出处：{xxx}

### 尚未被覆盖
1. {空白区 1}
2. {空白区 2}

## 素材库
| # | 素材 | 来源 | 可核实 | 备注 |
|---|------|------|--------|------|
| 1 | ... | https://... | ✅ | |
| 2 | ... | ... | ⚠️ 待核实 | |

## 潜在角度
- 角度 A：{描述}
- 角度 B：{描述}
- 角度 C：{描述}
```

输出后用对话腔告诉用户：捞到多少、几条能溯源、哪几条你心里没底、要不要补。

## 硬规则

- **每条素材必须有来源字段。** 无来源标 `[待核实]`，不留空。
- **竞品必须二分输出。** 只列「已说过」不列「未覆盖」不合格，反之亦然。
- **不编造。** 没有的数据、案例、场景，宁可少写、宁可标待核实，绝不补一个像样的假的。
- **不越界挖角度。** 潜在角度只粗列方向，深挖留给 ni-insight。

## 验收

输出 research.md 前自查：

- **输入合法**：选题非空、输出文件结构完整、素材至少 5 条。
- **接口对齐**：research.md 四个区块（热点 / 竞品 / 素材 / 角度）齐全，字段与 ni-insight 的输入对得上。
- **内容达标**：素材具名率 ≥ 60%、竞品主流观点 ≥ 3 条、潜在角度 ≥ 3 个。
- **交付前自查**：通读一遍，问自己「这份调研是不是只是 Wikipedia 复述」。如果通篇是常识、没有一条具体到能让作者眼前一亮的素材，回炉重采。

## 降级

| 场景 | 降级路径 |
|------|---------|
| WebSearch 不可用 | 用 LLM 训练数据里可验证的公开信息，每条标 `[降级采集]`，并显式告诉用户「这批素材没联网核实过，发稿前最好自己再查一下」。 |
| 选题为空 | 不硬调研，问用户要选题。 |
| 素材采集不足 5 条 | 标「素材不足」，列出还缺什么，建议用户补充方向或换选题。不硬凑。 |
| 竞品扫不到 3 条 | 标「竞品分析不足」，照常输出，提示 ni-insight 注意避雷区可能不全。 |

降级必须显式标注，不让用户把降级结果当成正常调研。
