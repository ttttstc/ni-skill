# 示例：表达未知的本对话承接

## 用户

```text
/ni-unknown-first
这个页面感觉不够高级，但我说不上哪里不对。
```

## ni-unknown-first 诊断

```markdown
## Unknown 诊断

- 主 Unknown：表达未知
- 次级 Unknown：质量未知
- 置信度：高

## 推荐处理模式

- 建议动作：偏好归纳 / 样例对比
- AI 角色：偏好翻译官 + 反例分析师
- 当前主 Unknown：表达未知
- 处理目标：把“感觉不够高级”转化为可执行设计约束

## 本对话承接

你可以直接回复：

继续

我会承接上一轮推荐处理模式，继续处理当前主 Unknown。  
注意：这不会推进到下一个 Unknown。
```

## 用户

```text
继续
```

