# 示例：用户起点诊断

## 用户

```text
/ni-unknown-first
这个页面感觉不够高级，但我说不上哪里不对。
```

## 诊断片段

```markdown
## Unknown 诊断

- 主 Unknown：表达未知
- 次级 Unknown：质量未知
- 置信度：高

## 用户起点依据（仅详细诊断时展示）

> 默认任务包不展示本节；这里仅用于说明内部判断如何影响下游。


- 已显性说明：用户已经判断当前页面“不够高级”。
- 可能隐性知道：用户可能能通过对比识别哪些方向更接近“高级感”。
- 当前判断盲区：缺少可执行的设计约束，例如信息密度、配色、排版、文案语气、视觉层级。

## 真正的行家视角

- 任务层级：质量层
- 推荐行家：品牌设计评审 + 信息架构师 + 偏好翻译官
- 选择理由：当前问题不是直接重做页面，而是把用户已经能感知但尚未表达的质量判断转成可执行约束。
```

## 下一阶段任务包方向

下游模式可以使用样例、反例、方向对比或轻量原型帮助用户显化隐性标准。不要只问“你喜欢什么风格”。
