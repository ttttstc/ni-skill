# 本对话承接协议

## 目标

减少用户手动复制下一阶段任务包的摩擦。

`ni-unknown-first` 每次诊断后都可以给出两个出口：

1. 本对话承接：用户回复“继续”，当前对话直接进入上一轮推荐处理模式。
2. 跨上下文复制：用户复制任务包到其他 AI、新会话、专门 skill 或代码 agent。

## 关键语义

```text
“继续” = 承接上一轮推荐处理模式，用来处理当前主 Unknown。
“再次运行 /ni-unknown-first” = 重新诊断，并判断是否推进 Unknown 队列。
```

## 承接时必须遵守

1. 不重新诊断。
2. 不推进到下一个 Unknown。
3. 不提升后续 Unknown 队列。
4. 只进入上一轮推荐处理模式。
5. 该模式只服务于处理上一轮主 Unknown。
6. 先声明当前承接的 Unknown、模式、角色、停止条件。
7. 然后按任务包开始工作。

## 推荐承接开场

```markdown
我按上一轮推荐模式继续。

- 当前主 Unknown：{主 Unknown}
- 处理模式：{推荐处理模式}
- AI 角色：{角色}
- 本阶段目标：{目标}
- 停止条件：{停止条件}

下面开始处理当前主 Unknown。
```
