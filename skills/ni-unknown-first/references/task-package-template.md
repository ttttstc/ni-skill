# 下一阶段任务包模板

`ni-unknown-first` 生成的任务包默认用于**本对话承接**，因此不要默认暴露大段“当前上下文”和“用户起点”。这些信息应作为内部诊断依据，用来影响角色、目标和工作规则，而不是直接塞进提示词正文。

只有当用户明确要求“复制到新会话 / 跨工具使用 / 完整提示词”时，才生成跨会话版，并只带**最小必要上下文**。

## 默认：本对话承接版

```text
请你扮演「{AI 角色}」。

角色选择依据：
{简短说明这个角色为什么是当前任务层级和决策场景下的真正行家。}

当前主 Unknown：
{主 Unknown 名称}

阶段目标：
{本阶段要关闭什么 Unknown。}

你可以使用的方法：
{调研 / 样例 / 原型 / 反例 / 代码库探索 / 质询 / 验收设计等，按需列出。不要机械限制下游方法。}

工作规则：
1. 所有动作都必须服务于关闭当前主 Unknown。
2. 不要重复追问用户已经明确的信息。
3. 如果用户有隐性判断但说不清，请通过样例、反例、对比、原型或必要调研帮助显化。
4. 如果用户缺少判断框架，请先建立判断框架，再推进具体任务。
5. 如果需要调研、原型、代码扫描或对比分析，请说明它服务于哪个判断。
6. 不要把其他次级 Unknown 混进当前阶段，除非它们直接影响当前主 Unknown 的关闭。
7. 本阶段结束后，输出可回流给下一次 /ni-unknown-first 重新诊断的信息。

输出格式：
## 当前理解
## 处理步骤
## 阶段产出
## 关闭条件检查
## 保留 Unknown
## 回流给下一次诊断的信息

停止条件：
{满足什么条件后，本阶段完成。}
```

## 可选：跨会话复制版

仅当用户明确要求“复制到新会话 / 发给其他 AI / 完整提示词”时，使用跨会话版。

```text
请你扮演「{AI 角色}」。

角色选择依据：
{简短说明这个角色为什么是当前任务层级和决策场景下的真正行家。}

最小必要背景：
{只写下游完成任务必须知道的已确认事实、目标和约束。不要复制完整对话。}

当前主 Unknown：
{主 Unknown 名称}

阶段目标：
{本阶段要关闭什么 Unknown。}

用户已明确的信息不要重复询问；用户尚未表达但可能需要通过选择、样例、对比或原型显化的判断，请在工作过程中自然引导。

你可以使用的方法：
{调研 / 样例 / 原型 / 反例 / 代码库探索 / 质询 / 验收设计等，按需列出。}

工作规则：
1. 所有动作都必须服务于关闭当前主 Unknown。
2. 如果需要使用调研、原型、代码扫描或对比分析，请说明它服务于哪个判断。
3. 不要把其他次级 Unknown 混进当前阶段，除非它们直接影响当前主 Unknown 的关闭。
4. 产出需要能回流到下一次 /ni-unknown-first 重新诊断。

输出格式：
## 当前理解
## 处理步骤
## 阶段产出
## 关闭条件检查
## 保留 Unknown
## 回流给下一次诊断的信息

停止条件：
{满足什么条件后，本阶段完成。}
```

## 生成规则

- 默认生成“本对话承接版”。
- 不默认输出“当前上下文”章节。
- 不默认输出“用户起点”章节。
- 用户起点仍必须用于内部判断：避免重复问已明确的信息；对隐性判断用样例 / 对比显化；对判断盲区先建立框架。
- 跨会话版只保留最小必要背景，不复制完整上下文。
