# ni-fde-copilot

中文 | [English](./README.en.md)

> 把面向内行的长篇、多来源专业资料，转化为聪明外行能够理解、判断、应用和追问的领域学习指南。

`ni-fde-copilot` 是一个独立的 FDE 陌生领域学习技能。它不按原资料顺序做摘要，而是先建立最小充分领域模型，找出外行会卡住的认知缺口，再沿因果连续的学习主线组织内容。默认使用严格的两阶段确认门禁，避免在主题、范围和知识结构尚未校准时直接生成长文。

## 适用场景

- 客户会前快速进入陌生行业
- 研读专业书籍、PDF、研究报告或内部方案
- 将课程视频、PPT、图表和板书转成可独立理解的文字
- 整理专家访谈、会议录音和跳跃式转录
- 需要达到「可以与专业人士对话」而不只是「知道大概」

## 快速开始

安装整个仓库后，在新的代理会话中提供资料，并调用 `$ni-fde-copilot`。说明你的会议、决策或学习目标，然后要求先输出学习蓝图，确认后再写完整指南。

第一次响应只会给出五部分学习蓝图：

1. 主题识别
2. 知识结构梳理
3. 关键例子盘点
4. 认知缺口预判
5. 预期产出

确认后，技能才会生成引导式学习指南、迁移挑战和对话准备度。

## 工作方式

工作顺序是：

1. 确定学习任务。
2. 清点并完整读取所有资料。
3. 建立领域模型和认知缺口。
4. 组织因果连续的学习主线。
5. 输出五部分学习蓝图并等待确认。
6. 确认后生成引导式学习指南。
7. 完成质量审查、迁移挑战和对话准备度。

### 第一阶段：学习蓝图

第一阶段用于校正主题、范围、领域模型、案例、认知缺口、学习路径和目标能力。未确认前不会起草或预览第二阶段正文。

### 第二阶段：引导式学习指南

正文沿「困惑、机制、案例验证、新问题、下一概念」推进。每个核心概念都要覆盖定义、重要性、机制、判断、应用、常见错误、相似概念、边界和实际行动；每个承载推理的案例都要说明场景、机制、替代做法和迁移原则。

## 输入与降级边界

技能可处理文本、网页、PDF、书籍、报告、PPT、图表、视频、音频和转录，但实际读取能力取决于当前代理环境提供的工具。

- 长资料按语义单元分块，并维护资料清单，避免资料静默丢失。
- 视频和演示需要检查承载推理的视觉信息，不能只读字幕。
- 音频和口语材料需要还原指代、说话者立场和有价值的试错过程。
- 任务范围内的资料无法访问、片段缺失或关键视觉未取得时，技能会明确阻断对应范围，不会假装已经读完。

## 证据边界

承重结论会区分五种状态：

| 状态 | 含义 |
|---|---|
| `SOURCE` | 原资料明确支持 |
| `INFERENCE` | 根据已给资料进行的可复核推导 |
| `EXTERNAL` | 为补齐关键认知缺口而核验的外部知识 |
| `UNKNOWN` | 当前资料不足以回答 |
| `NEED VALIDATION` | 可以推理，但实际决策前仍需确认 |

外部知识只能用来补齐阻断理解的前置知识或机制，不能静默改写原资料，也不能掩盖资料之间的冲突。

## 快速模式例外

只有用户明确要求快速模式、极短时间版本、一次性输出或跳过确认时，才会跳过默认门禁。快速模式会改变知识选择，优先保留根本问题、高杠杆概念、核心机制、关键区分、判断规则、失败边界、未知项和专家问题，并明确列出主动舍弃项。

如果用户明确要求「先确认再写」，快速模式也不能跳过确认。

## 能力边界

目标是「对话级领域流利度」，不是替代持证专家、完整专业训练或真实项目验证。最终的对话准备度会明确区分：已有充分依据的内容、可以推理但需要确认的内容、当前资料无法支持的内容，以及下一步最值得询问专家的问题。
