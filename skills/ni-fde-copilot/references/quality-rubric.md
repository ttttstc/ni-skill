# 能力导向质量标准

## 目录

1. 覆盖审查

5. 对话准备度

## 1. 覆盖审查

交付前确认：

- 每个核心概念都出现在指南中，并通过九项概念检查。
- 每个桥接概念都关闭了促使它出现的认知缺口。
- 每个承载推理的案例都得到完整展开。
- 蓝图中列出的主动舍弃仍然是有意舍弃。
- 每个预测出的关键认知缺口都得到修复。
- 根本问题、角色、机制、判断规则和边界组成一张连贯的模型。

任一项失败，就先修复指南再交付。

## 2. 推理审查

检查每个重要转折：

- A 是否直接跳到 C，而目标读者其实需要 B？
- 是否只描述行为，没有解释产生行为的机制？
- 是否把有条件的结论写成了普遍规律？
- 是否提到相似概念，却没有给出影响判断的区别？
- 读者能否在新案例中识别并应用这个概念？
- 每一节是否自然产生下一节的学习需要？

如果文字虽然技术上正确，却仍要求读者跳出去查资料，就不能通过审查。

## 3. 证据与效率审查

确认：

- 原资料的重要结论仍然忠实于来源。
- `INFERENCE` 没有被写成来源原话。
- `EXTERNAL` 补充已被识别并核验。
- 冲突仍然可见。
- `UNKNOWN` 和 `NEED VALIDATION` 没有被合理猜测填满。
- 低价值细节没有挤占核心心智模型、机制、判断规则、区分、边界或案例。
- 中文正文遵守写作标准中的标点和引号规则。

## 4. 迁移挑战

在文档末尾加入少量原资料没有出现的新场景。根据学习任务测试最相关的能力：

- 用自己的话解释
- 连接概念与机制
- 区分相近选项
- 在条件改变时推理或预测
- 诊断新案例
- 应用规则或方法
- 说明结论边界
- 迁移到结构相似的例子
- 向专家提出高价值问题
- 校准信心和证据需求

优先使用两到五个有深度的场景，而不是长测验。不要只问定义。

## 5. 对话准备度

结尾分成四组简洁内容：

1. 读者有充分依据可以讨论的主题。
2. 读者可以推理，但应该先确认的主题。
3. 当前资料无法支持的主题。
4. 下一步最值得向领域专家询问的问题。

这是「不要装懂」机制。它要降低虚假信心，而不是鼓励读者表演专业能力。

## 6. 可选缺口修复

如果用户答错挑战：

1. 找到最小的缺失心智连接。
2. 选择不同的修复方式：对比例、因果链、反例、具体场景、类比、前置知识、决策树或改变解释粒度。
3. 只修复这一个连接。
4. 用新场景重新测试。
5. 达到目标能力或触及证据边界后停止。
