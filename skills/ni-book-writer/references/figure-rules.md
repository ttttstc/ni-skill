# 图规范（技术书种）

> 图表是承载复杂度的主体，文字只点睛、解释图读不出的内容。三件套：占位 + 逐图说明 + 读图指引。

## 应配尽配（硬性）
以下内容**必须**配图或表，纯文字描述视为不达标：
- 时间先后 / 跨组件流程 → 时序图
- 多步判定 → 流程图 / 决策树（菱形标判定问题）
- 状态与生命周期 → 状态图（主状态 + 重要终态）
- 两个概念并排对比 → 对照表（维度做行、概念做列）
- 条件组合 → 枚举表（条件 → 结果）
- 概念结构关系 → 结构图（每章基础概念节必配一张）

## 占位 + 说明 + 读图指引
- 正文放位图占位 `![图 X-N](pic/chXX-名/fig-NN.png)`，紧跟一段"读图指引"（教读者怎么看、抓哪两点）。
- 每张图配一份"逐图说明"（写在生图说明文件里）：框内文字、连线、标注、唯一强调点——看说明就能画出确定的图。
- **占位编号 ↔ 说明 1:1 对齐**，别留孤儿（重构挪动内容时尤其要核对）。
- 位图由生成模型出图时**逐张校字**：中英混排的长标签容易被串字 / 造词，出图后必须核对图内文字与说明一致。

## 图内文字规则（硬性）
- 只保留机制词，**不含导航词**：篇号、节号、"详见 / 见 X.Y / 本章 / 下一节"一律不进图（那是正文的事）。
- 中文叙述，专名保留英文原形（workflow、runner、SHA…），大小写同官方；非专业技术名词用中文。
- 不用 emoji、不用 ✓ / ✗ / ⚠ 替代文字——用"成功 / 失败 / 是 / 否 / 不触发"等中文词。
- **每张图至多一处强调**（如一个高亮色标关键节点 / 关键边），多了就失去强调意义。

## 全局风格基准（开工前定一次）
配色（按角色分：编排 / 执行 / 信任 / 中性…，每色固定填充/边框/文字）、线条与箭头（主干实线、约束/不透传虚线、时序图同步实线返回虚线）、字体（中文无衬线 + 英文等宽，同级字号一致）、版式（留白充足、横版优先、纯白背景、2x 分辨率出 PNG 适合印刷）。
