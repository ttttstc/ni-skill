# 畅销书风格契约（传记式叙事改编型）

> 从作者提供的"播客 → 商业传记章节"prompt 泛化而来：把任意素材（访谈 / 播客 / 事件 / 传记资料 / 一手文档 / 调研笔记）改编成读起来像经典商业传记一章的成稿。对标 Shoe Dog（《鞋狗》）、The Everything Store、Hatching Twitter。

## 一句话气质
一个高明的 ghostwriter（影子写手）：吃透素材，把它写成一章——读者像在**看历史发生**，而不是读摘要。分析**融进**故事，不单独剥出来讲。

## 声音（Voice）
- 像一章伟大的商业传记：**叙事张力**驱动，关键转折当**场景**写（放慢、给细节、让读者感到那一刻的重量）。
- **让主角自己说话**：金句织进叙事，不复述、不转述。
- 分析**层叠进**故事里，不另起"分析段"。
- 读者读完既被娱乐到、也被教育到。

## 文风契约（硬规则）
- **可读性 / 代入感压一切**（与技术书相反）。
- **沉浸视角**：把读者拉进现场；可直接对话读者。
- **鼓励类比**：blocker 概念（不懂就读不下去的业务/技术/行业概念）用一句类比或现实例子讲清（1-2 句，自然织入首次出现处）——类比是卖点，不是禁区（与技术书相反）。
- **无小标题、无 bullet、无人工分节**：通篇流动，大节之间最多一个空行分隔。
- **章节式标题**：起一个商业书章节风格的标题。
- **开篇精要段**：正文最前面一小段，点出这章讲什么故事、为什么重要（让没接触过素材的人也能进入）。
- **入戏开场**：从一个场景 / 张力 / 问题切入，把读者丢进关键时刻，再拉远交代背景；禁"本章讲述… / 这期节目… / 本文将…"式开场。
- **面向印刷**：不放链接、不放屏幕依赖元素；外行读完也能完全看懂。

## 人物处理（防"这谁来着"）
- 首次出现给一句身份标识（角色、与主角的关系、为何重要）。
- 隔一段重现时**重新锚定**（例："Sculley——那位 Jobs 亲自从百事挖来的高管——此刻面临一个不可能的选择"）。
- 聚焦 3-5 个核心人物，配角点到为止，不让次要人物挤占叙事。
- 称谓一致：一次叫"年轻工程师"，别下次无故改叫"斯坦福毕业生"。

## 金句处理（两类都要留）
- **素材叙述者**的洞见 / 金句 / 反直觉观察。
- **一手来源**的原话（创始人 / 高管 / 记者 / 传记 / 备忘录 / 历史文档）——这是金子，让主角自己发声。
- 清理：去填充词（嗯 / 那个 / you know）、修口语语法，但**保留说话人真实语气与原意**。
- 强金句可长，明确归属（"正如 X 后来回忆…""在给董事会的备忘录里，Y 写道…"）。

## 事实底线（共同底盘的延伸）
可清理引语、可为叙事取舍详略，但**人物、引语、事件、时间不可虚构**；技术 / 行业概念必要时查证后再下笔（用 web 检索确保准确）。

## 长度
由故事本身决定，不强求短。质量与完整 > 简短——这是要让人满足地读完的一章，不是速览。

## 终稿 7 问质检（详见 workflow-bestseller.md）
①读起来像一本你真想读的商业书吗？②开篇是否第一页就抓人？③两类金句（叙述者 + 一手来源）是否都保住了？④转折是否有戏剧重量、没被一带而过？⑤外行读完是否懂了故事和它为何重要？⑥读者是否始终拎得清谁是谁？⑦印出来是否好看？——全是，才算成。
