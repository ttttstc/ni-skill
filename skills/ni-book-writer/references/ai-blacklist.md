# AI 腔黑名单（两种书种通用，终稿前过一遍）

> 让书读起来像人写的，不像模型生成的。逐条自查，命中就改。

## 词汇 / 短语层
- **注水副词堆叠**：极其 / 非常 / 彻底地 / 完全地 / 真正地 / 无比 / 十分。
- **万能套话**：值得注意的是 / 总而言之 / 综上所述 / 由此可见 / 不难看出 / 显而易见 / 众所周知 / 老生常谈。
- **教科书过渡腔**：接下来我们 / 让我们一起 / 首先…其次…最后（机械三段）/ 至此。
- **空心形容**：强大的 / 优雅的 / 丝滑的 / 革命性的 / 颠覆性的（除非有具体支撑）。
- **自夸 / 填充**：本章最该收藏 / 最重要的一张表 / 一锤定音 / 灵魂 / 核心中的核心 / 一次说清。

## 句式 / 结构层
- 排比三连凑气势（rule of three 滥用）。
- 每段开头都用同一种连接词起手。
- "不是 X，而是 Y"句式滥用（negative parallelism 过量）。
- em dash（——）过载：一段里三四个就该拆句。
- 段段等长、节节同构的机械节奏——人写的有长短起伏。
- 结尾强行升华 / 喊口号（尤其非随笔类）。

## 内容层
- **模糊归因**："有人认为 / 研究表明 / 业界普遍"——要么给具体来源，要么删。
- **正确的废话**：放之四海皆准、删了不损失信息的句子。
- **假精确**：编造的数字、来源不明的百分比、未经核实的具体日期。

## 两种书种的差异化提醒
- **技术书**：另查"我"字（应为"用户"）、装饰比喻（应删，留行业标准术语）、含糊词与标注腔（见 `accuracy-rules.md`）。
- **畅销书**：另查"摘要腔"（"本章讲述了…"）、残留的小标题 / bullet（应熔进叙事）、人物指代漂移（"这谁来着"）。
