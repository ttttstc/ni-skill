# 畅销书生产管线（传记式叙事改编型）

> 从作者的"播客 → 商业传记章节"prompt 泛化。配合 `style-bestseller.md` 使用——把任意素材改编成一章读起来像 Shoe Dog 的成稿。

## 输入模式
素材（访谈 / 播客转写 / 事件资料 / 传记 / 一手文档 / 调研笔记）→ **戏剧化改编**成章。先吃透全部素材，再动笔。

## 6 步管线

### 第 1 步 · 理解弧线
通读全部素材，找出：**中心叙事**（讲的是什么故事、戏剧问题是什么）、**关键人物**（主角 / 对手 / 配角）、**3-5 个转折点**（一切改变的时刻）、**利害**（什么在险中、可能怎么砸）。好故事有形状：开场铺垫 → 张力上升 → 关键抉择 → 收束（或悬念）。先找到这个形状，再写。

### 第 2 步 · 人物地图
首现带身份、重现再锚定、聚焦 3-5 人、称谓一致（见 `style-bestseller.md` 人物处理）。让读者永远不必停下问"这谁来着"。

### 第 3 步 · 讲清 blocker 概念
扫出"不懂就读不下去"的业务 / 技术 / 行业概念。每个用一句类比或现实例子讲清（1-2 句），自然织入首次出现处；技术概念必要时查证（用 web 检索确保准确）。目标读者：聪明好奇的外行——读商业书、看科技新闻，但不懂每个行业细节。

### 第 4 步 · 采集金句
两类都收（见 `style-bestseller.md` 金句处理）：素材叙述者的洞见、一手来源的原话。清理填充词、修口语语法，保原声原意，明确归属。强金句可长。

### 第 5 步 · 搭建叙事
- **开场**：用场景 / 张力 / 问题入戏，把读者丢进关键时刻，再拉远铺背景；禁"本章讲述… / 这期节目…"。
- **中段**：按时间或主题推进（哪个更服务故事就用哪个），转折当**场景**放慢、给细节、在关键节点上金句。
- **收尾**：余韵——后来怎样、意味着什么、留下什么教训或追问。

### 第 6 步 · 编织成章
叙事 + 分析 + 金句熔成一篇流动的稿：**无小标题 / 无 bullet / 无人工分节**（大节之间最多一个空行）；起一个章节式标题；开头加一段**精要**（这章讲什么、为何重要）；让没接触过素材的外行也能完全看懂；面向印刷（无链接、无屏幕依赖元素）。

## 终稿 7 问质检（逐条自问，全"是"才算成）
1. 读起来像一本你真想读的商业书，而不是播客摘要？
2. 开篇是否第一页就抓人？
3. 两类金句（叙述者 + 一手来源）是否都保住了？
4. 转折是否有戏剧重量，没被一带而过？
5. 外行读完是否懂了故事和它为何重要？
6. 读者是否始终拎得清谁是谁？
7. 印出来是否好看？

任一"否"→ 回到对应步骤重打磨。
