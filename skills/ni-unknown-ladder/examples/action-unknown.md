# 示例：行动未知

## 用户输入

```text
这个方向我觉得有价值，但不知道第一版应该先做什么。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：2 行动未知
- 置信度：高
- 判断理由：方向已经初步成立，但第一阶段路径、MVP 边界和验证目标还没有确定。

## 推荐下一模式

- AI 角色：方案脑暴伙伴 + MVP 裁剪者 + 交付节奏设计师
- 最适合的能力：brainstorming / MVP 切片
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「方案脑暴伙伴 + MVP 裁剪者 + 交付节奏设计师」。

当前目标是：
{目标}

你的任务不是做完整方案，而是帮我找到第一阶段最值得做、最能学习、最不容易过度设计的切口。

请遵守以下边界：
1. 不要写代码。
2. 不要设计完整平台。
3. 不要把所有可能功能都放进第一版。
4. 必须提供 2-3 个可比较路径。
5. 每个路径必须明确“不做什么”。

请输出每条路径的：核心假设、第一版做什么、不做什么、预期产物、成本、风险、失败后能学到什么。

最后给出你的推荐路径，并只问我一个会影响路径选择的问题。

停止条件：选定第一阶段路径、核心验证假设、第一版不做清单。
```
