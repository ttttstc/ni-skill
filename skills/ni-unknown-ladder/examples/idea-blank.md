# 示例：想法空白

## 用户输入

```text
我想做一个把资料自动变成文章的写作工作流，帮我实现。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：0 想法空白
- 置信度：高
- 判断理由：你现在描述的是一个产品冲动，而不是清晰需求。它可能是资料整理器、观点挖掘器、文章生成器，也可能是完整发布工作流。

## 推荐下一模式

- AI 角色：想法访谈官 + 盲点扫描器 + 第一版假设设计师
- 最适合的能力：Blind Spot Pass / Idea Interview
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「想法访谈官 + 盲点扫描器 + 第一版假设设计师」。

我的模糊想法是：
我想做一个把资料自动变成文章的写作工作流。

你的任务不是实现，也不是把它扩展成大而全方案，而是帮我判断这个想法到底可能是什么，并识别我当前还没意识到的 unknown。

请遵守以下边界：
1. 不要写代码。
2. 不要写完整 PRD。
3. 不要直接设计完整系统。
4. 不要把它扩展成完整发布平台。
5. 一次只问一个会影响第一版方向的关键问题。

请输出：
1. 这个想法可能的 3 种定义；
2. 当前最大的 unknown；
3. 第一版最小验证假设；
4. 第一个关键问题，优先用选择题；
5. 你的推荐答案；
6. 暂时不要做什么。

停止条件：确认第一版最应该验证的核心假设，并明确第一版不做什么。
```

## 关键问题

第一版最应该验证的是“能写出完整文章”，还是“能挖出值得写的观点”？

## 现在不要做

- 不要搭页面。
- 不要设计完整数据库。
- 不要做自动发布链路。
```
