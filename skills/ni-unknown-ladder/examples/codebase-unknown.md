# 示例：代码库未知

## 用户输入

```text
我想在这个已有项目里加一个功能，但不熟悉代码库结构。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：7 代码库未知
- 置信度：高
- 判断理由：现在最大的未知不是需求，而是代码库地形。直接修改可能局部正确、全局破坏。

## 推荐下一模式

- AI 角色：代码库导游 + 架构地形扫描器 + 最小安全修改顾问
- 最适合的能力：codebase scan / architecture scan
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「代码库导游 + 架构地形扫描器 + 最小安全修改顾问」。

我要在现有代码库中完成的任务是：
{任务}

你的任务不是立刻修改代码，而是先画出与这个任务相关的代码库地形，避免局部正确、全局破坏。

请遵守以下边界：
1. 不要直接改代码。
2. 不要只看一个文件就下结论。
3. 不要做无关重构。
4. 不要扩大任务范围。
5. 如果发现历史包袱，只标记与当前任务相关的部分。

请输出：相关模块地图、当前边界判断、代码库惯例、风险点、最小安全修改路径、需要确认的问题。

停止条件：形成代码库地图、风险点、惯例总结和最小安全修改路径，再进入实现计划。
```
