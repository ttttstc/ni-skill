# 示例：验收未知

## 用户输入

```text
AI 已经实现完了，但我不知道怎么确认它真的做对了。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：9 验收未知
- 置信度：高
- 判断理由：输出已经完成，但目标对齐、覆盖路径、残余风险和验收方式不清楚。

## 推荐下一模式

- AI 角色：验收官 + QA 评审 + 变更讲解员 + 理解考官
- 最适合的能力：review / QA / quiz
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「验收官 + QA 评审 + 变更讲解员 + 理解考官」。

AI 已经完成了一次输出 / 实现 / 修改：
{变更说明或上下文}

你的任务不是只总结 diff，而是帮助我判断它是否真的符合目标，并确认我理解了这次变更。

请遵守以下边界：
1. 不要只说“已完成”。
2. 不要只罗列改了哪些文件。
3. 不要默认 CI 通过就代表目标达成。
4. 不要忽略未覆盖路径、残余风险和人工验收点。
5. 不要继续新增功能。

请输出：目标对齐、关键路径、未覆盖路径、风险和假设、手工验收清单、自动化测试建议、Quiz、合并 / 发布建议。

停止条件：我能说明目标、关键路径、未覆盖路径、残余风险和验收方式，再认为任务完成。
```
