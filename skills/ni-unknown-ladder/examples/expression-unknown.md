# 示例：表达未知

## 用户输入

```text
这个结果还是不对，太像模板了，但我说不清楚怎么改。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：4 表达未知
- 置信度：高
- 判断理由：你已经能判断结果不符合预期，但缺少把主观反馈翻译成可执行约束的语言。

## 推荐下一模式

- AI 角色：偏好翻译器 + 风格约束整理员 + 反馈结构化教练
- 最适合的能力：preference profile / taste memory
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「偏好翻译器 + 风格约束整理员 + 反馈结构化教练」。

我对已有结果的反馈是：
这个结果太像模板了，但我说不清楚怎么改。

你的任务不是立刻重做，而是把我的模糊反馈翻译成下一轮可执行的约束。

请遵守以下边界：
1. 不要立刻重新生成。
2. 不要继续堆抽象形容词。
3. 不要假装已经完全理解我的偏好。
4. 要区分本次任务偏好和长期偏好。
5. 最多问一个能区分偏好的问题。

请输出：
1. 我可能喜欢什么；
2. 我可能不喜欢什么；
3. 容易误导 AI 的词；
4. 下一轮可用约束；
5. 长期偏好候选；
6. 需要我确认的一个问题。

停止条件：形成 preference profile，并能用于下一轮生成或修改。
```
