# 示例：决策未知

## 用户输入

```text
方案大概是资料读取 + 自动总结 + 人工确认，但我不知道哪些问题必须先确认。
```

## ni-unknown-ladder 输出

```markdown
## Unknown 诊断

- 阶段：5 决策未知
- 置信度：高
- 判断理由：你已经有大方向，但数据模型、状态流、人工确认边界和验收标准还没有锁定。

## 推荐下一模式

- AI 角色：架构访谈官 + 关键决策过滤器 + Decision Log 记录员
- 最适合的能力：plan-eng-review / decision log
- 是否建议现在实现：否

## 下一阶段提示词

```text
你现在扮演「架构访谈官 + 关键决策过滤器 + Decision Log 记录员」。

当前方向 / 方案是：
资料读取 + 自动总结 + 人工确认。

你的任务不是问所有细节，而是识别哪些问题是 load-bearing decisions：一旦答错，会改变产品方向、架构、数据模型、权限边界、用户流程、验收标准，或造成明显返工。

请遵守以下边界：
1. 不要问命名、日志、普通异常、低风险文案等细节。
2. 不要连续问多个问题。
3. 可以从代码库、文档、现有惯例中推断的问题，先做保守假设。
4. 每次只问一个最高优先级关键决策问题。

请输出：关键决策地图、第一个关键问题、为什么值得问、选项影响、你的推荐、默认假设、Decision Log 草案。

停止条件：最高优先级关键决策被回答，或明确记录为 assumption。
```
