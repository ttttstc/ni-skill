# 配图 prompt 模板库

> 本文是 ni-article-image-gen 的模板参考：封面 3 策略怎么写、6 种内文配图类型的结构化模板、实体锚定的正反例、图库备选关键词怎么生成。

---

## 1. prompt 通用结构

每条 prompt 按这个骨架写：

```
{画面类型} of {文章实体 1} 和 {文章实体 2}，
{构图描述}，{风格关键词}，{色板}，{调性}
```

四个必填部分：

1. **类型** —— 封面是 3 策略之一，内文是 6 类型之一。
2. **实体** —— 至少 2 个文章里真实出现的工具 / 概念 / 场景。
3. **构图** —— 画面怎么摆，焦点在哪。
4. **视觉锚点** —— 风格关键词 + 色板 + 调性（内文配图统一复用封面定下的锚点）。

---

## 2. 封面 3 策略写法

### 直觉冲击型

用一个视觉隐喻直接把核心观点砸到读者眼前。

- 写法：找文章核心论点里的对立 / 反转，用一个画面把它视觉化。
- 例（文章讲「AI 不是替你写得更快，是替你不写不该写的代码」）：
  > 一只手停在键盘上方没有落下，屏幕上大段代码正在被轻轻擦去，极简扁平插画，克制的留白

### 氛围渲染型

不讲观点，先把情绪 / 场景的氛围托出来。

- 写法：抓文章里最有画面感的那个真实场景，渲染它的光影和情绪。
- 例（文章开头是凌晨流水线第三次失败）：
  > 凌晨的工位，一块屏幕亮着红色的失败日志，房间其余部分陷在暗处，冷色调，安静而紧绷的气氛

### 信息图表型

用图形 / 图标 / 数据可视化，适合干货、清单、测评。

- 写法：把文章的核心结构（几个维度、几个步骤、一张对比）做成图形。
- 例（文章是「评估工具看三条标准」）：
  > 三个并排的图标分别代表使用频次、配置成本、回滚难度，简洁的信息图风格，标签清晰

3 组必须是 3 个不同方向，不是一个想法换三个颜色。

## 3. 6 种内文配图类型模板

### infographic — 数据 / 指标

```
信息图，展示 {文章里的具体数据/指标}，区域分块，每块带标签标注 {实体}，
扁平风格，{视觉锚点}
```

### scene — 叙事 / 情绪

```
场景插画，{文章里的真实场景}，焦点是 {主体实体}，氛围光影烘托 {情绪},
{视觉锚点}
```

### flowchart — 流程 / 步骤

```
流程图，从 {起点实体} 到 {终点实体}，中间是 {文章里的步骤节点}，
节点用箭头连接，简洁，{视觉锚点}
```

### comparison — 对比

```
左右分栏对比图，左边 {方案A实体}，右边 {方案B实体}，中间分隔线，
各自标注关键差异，{视觉锚点}
```

### framework — 概念模型 / 架构

```
架构示意图，{文章里的概念模型}，层级节点表示 {实体1、实体2 的关系}，
关系用连线，{视觉锚点}
```

### timeline — 时间线

```
时间轴，从 {起始时间点} 到 {结束时间点}，里程碑标记 {文章里的关键事件}，
横向排列，{视觉锚点}
```

## 4. 实体锚定正反例

**反例（泛化，禁止）**：
> 一张科技感十足的插画，展现 AI 与未来，蓝色调，高级感

问题：没有一个文章实体。换任何一篇 AI 文章都能用 = 锚定失败。

**正例（锚定到位）**：
> 一份打开的 AGENTS.md 文件悬在半空，旁边 Claude Code 的光标正在读它，扁平插画，暖色调

为什么合格：「AGENTS.md」「Claude Code」是文章真实实体，没读过文章的人也能猜出这篇在讲 AI 协作规范。

**自检**：把 prompt 给没读过文章的人，他能猜出文章主题 → 过；只看到「科技插画」→ 回炉。

---

## 5. 图库备选关键词

万一用户不生图、想去图库（Unsplash 等）找现成的，每条 prompt 配一组备选检索词。

- 从 prompt 里抽 2-3 个最具体的名词，转成图库好搜的英文词。
- 例：prompt 锚定「凌晨工位 + 红色失败日志」→ 备选词 `late night desk`、`red error screen`、`dark office`。
- 备选词偏「场景 / 物件」，不要偏「概念」——图库搜不到「技术债」，但搜得到「credit card」。

---

## 6. 视觉锚点的传递

封面定稿后，从选中的那张抽出视觉锚点（色板 hex、风格关键词、调性），写进 `cover-prompts.md` 末尾。

内文配图的每条 prompt 结尾统一带上这组锚点，保证整篇文章的图风格一致——读者翻下来不会觉得每张图来自不同的人。
